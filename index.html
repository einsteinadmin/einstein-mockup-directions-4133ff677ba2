LLM lens

Rule 10 is the whole architecture: every floor is a real HTML content block that reads perfectly with JS off; the movers are decoration. Hero stays static (Q1/Q7/Q9 answered before any animation); floors carry Q2/Q6/Q8; footer FAQ carries Q3/Q5.

Quote-form foundation

The movers' illustration style must come FROM the Brand Kit world (real-photo site, illustrated accents — never clip-art). Quip bubbles use the form's orange-nudge idiom. The truck finale lands on the form's own booking invitation.

Preserve

  • All differentiator copy (each floor = one existing "reason")
  • Static hero answers + proof numbers
  • The quote form as the destination

Change

  • Page structure from stacked sections → one descending scene with landings
  • Differentiators from cards → floors with one argument each
  • Origin story → a framed photo in the lobby

Kill

  • Everything v1 killed, plus any second journey on other pages — this trick plays ONCE, on the homepage

Three moments that carry it

  • The first descent. The instant the visitor realizes the movers move WITH the scroll — that's the share-this-site moment.
  • Scroll-up comedy. Movers walking the couch backward upstairs. Free, honest, very Einstein.
  • The truck doors closing on the CTA. The product demo and the conversion are the same pixel.

Risks

  • Production: the sprite rig. 2 movers + couch, ~5 poses — an illustrator brief in days, but the style MUST match the brand or it reads clip-art (the one failure mode).
  • Scope discipline. 5–7 beats max. The Boat took a year at 222 illustrations; we are not doing that.
  • KP build cost — Laura confirmed budget for custom interactive components; this is where it goes.

LLM lens

Quote-form foundation

Maximal by definition — the form's screens, badges, and voice ARE the homepage's visual system. The site doesn't echo the form; it showcases it.

Preserve

  • "47 seconds" + "tiny math elves" copy
  • Pricing-page comparison content (promoted, redesigned)

Change

  • Why-us framing → chaos/order diagram
  • Comparison table → receipt component (reusable on Pricing)

Kill

  • Any hero metaphor photography (couples hugging boxes)

Three moments that carry it

  • The estimate in the hero. A real number on first paint — the category's biggest fear answered before a single claim is made.
  • Chaos → order. The one image that explains why a system beats a guess.
  • The receipt. Their fees itemized vs. our zero — the hotel-resort-fee analogy as a component.

Risks

  • Emotionally coolest of the four — needs the crew/story band to keep humans in frame (v1's Smart Move System had the same risk).
  • Numbers become public commitments — every stat on the page gets operationally graded.
  • VP sensitivity: example pricing must respect the soft variable-pricing guardrails (weekday nudge, never surge framing).
